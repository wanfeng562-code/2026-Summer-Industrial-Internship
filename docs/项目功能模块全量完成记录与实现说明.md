# 项目功能模块全量完成记录与实现说明

> 对照依据：`第1章-实训项目需求.pdf`。本文是持续维护的验收清单；只有代码、数据库迁移、接口与页面均具备时，才标记为“已完成”。

## 使用与迁移约定

在已有数据库完成 `ticket_system.sql` 与 `migrate_member_c_workflow.sql` 后，执行：

```sql
source ticketsystem/src/main/resources/static/migrate_full_requirements.sql;
```

该迁移为可重复执行脚本，增加坐席组、工单分类、账号在线状态及工单归档字段。生产环境执行前仍应先备份数据库。

需要扩充联调和展示数据时再执行：

```sql
source ticketsystem/src/main/resources/static/seed_rich_demo_data.sql;
```

扩充脚本只追加带独立前缀的数据，重复执行不会重复写入；新增 16 个账号、30 个订单、24 个工单，以及消息、日志、满意度、FAQ、策略和 AI 会话。已使用临时 MySQL 8.0.42 完成双次导入验证。

## 1. 账号、认证与权限

## 剩余验收（不再是代码缺口）

1. 在真实 MySQL 8.0 重新执行 `migrate_full_requirements.sql`，确认字段、表和中文分类均正确。
2. 重启 IDEA 后端和前端，用 USER/AGENT/组长/ADMIN 完成新增按钮与权限边界验收。
3. 在 FAQ 页面启用语义检索，用本机 `DASHSCOPE_API_KEY` 验证 `LLM` 模式、阈值和关键词降级。
4. 下载工单、FAQ、月度服务 CSV，使用 Excel/文本编辑器检查 UTF-8 BOM、中文和换行。
